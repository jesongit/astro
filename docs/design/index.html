PORTFOLIO UI · DESIGN OPTIONS

作品界面设计风格

依据 docs/plans/portfolio_development_plan.md 中定义的界面范围制作:每个风格包含 首页(精选作品优先)、作品列表(筛选 + 分页)、作品详情(能力 / 正文 / 截图 / 多平台下载) 三个视图,均支持深浅色切换。打开后用顶部「预览控制台」切换视图与主题;URL 加 #list / #detail 可直达对应视图。

A · 墨白 Editorial 杂志风

衬线大标题、暖纸底色、发丝分割线、单一朱砂强调色。安静克制、内容优先,阅读感最强,和文字博客气质最接近。

首页 作品列表 作品详情

B · 终端 Terminal 开发者风

等宽字体、暗色优先、面板窗口卡片、// 注释式标题、树状下载列表。程序员身份感最强,版本与仓库信息表达最自然。

首页 作品列表 作品详情

C · 硬边 Neo-Brutalism 粗野风

2px 粗描边、硬投影、撞色块与贴纸徽章。个性张扬、辨识度最高,互动反馈(按压缩放)有趣,适合想让作品集更「跳」的取向。

首页 作品列表 作品详情

D · 流光 Aurora 玻璃拟态

极光渐变背景、毛玻璃卡片、渐变胶囊按钮、大圆角与现代光晕。最「当代 SaaS」的观感,视觉层次丰富,深色模式下尤其出彩。

首页 作品列表 作品详情

第二批 · 结构实验

以 A、B 的设计语言和二次元方向为基础,重构版式结构而非只换配色:信息架构、导航模式、详情页骨架均与第一批不同。

E · 展卷 编辑部索引 · 基于 A

结构:首页「焦点聚焦 + 编号索引行」替代卡片栅格,文章走报刊双栏;列表是目录式总目 + 细线内联筛选;详情为左侧固定信息栏 + 右侧内容两栏,下载分册(Vol.1–5)。

首页 作品总目 作品详情

F · 工作台 IDE 主从式 · 基于 B

结构:整个站点套进 IDE 外壳——左侧竖向导航栏;首页与列表都是主从式浏览(左列表点击、右预览面板联动);详情为三栏(锚点目录 / 正文 / 固定元信息面板);文章是 git log 时间线。

首页 作品列表 作品详情

G · 梦绘 二次元手帐风

结构:首页是个人资料卡 + 技能条状态面板;精选作品为胶带贴纸卡册;文章是手帐日记胶囊;列表为剪贴簿错落布局 + 糖果筛选;详情是封面横幅 + 糖果状态 + 拍立得照片墙 + 「道具库」下载。
