为 Astro 打造的双栏博客主题,内置深浅色、阅读进度与全文搜索,一行配置即可接入 Pagefind。

主要能力

  • 深浅色主题一键切换,自动跟随系统
  • 内置 Pagefind 中文全文搜索
  • 文章阅读进度条与代码一键复制
  • 构建时自动生成 OG 分享图片
  • 响应式布局,移动端深度优化
  • 标签、归档与 RSS 全套支持

介绍

为什么写这个主题

市面上的博客主题大多功能繁杂、依赖沉重。Aurora 只保留写作真正需要的东西:清晰排版、快速检索与体面的分享卡片,其余一切都可以通过配置关闭。

// astro.config.ts
import aurora from "aurora-theme";

export default defineConfig({
  integrates: [aurora({ search: "pagefind" })],
});
少即是多——每一行默认样式都要为自己的存在辩护。

快速开始

  • 克隆模板仓库并安装依赖;
  • 修改 src/config.ts 中的站点信息;
  • 运行 pnpm dev 即可本地预览。
